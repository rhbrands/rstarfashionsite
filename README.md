# Rstar Fashion - Scaffold

This repo contains an initial Next.js + Tailwind scaffold for the Rstar Fashion site.

To get started locally:

```bash
npm install
npm run dev
```

## Security notes

- Never commit `.env` files, API keys, credentials, customer data, or production exports.
- The order API currently stores submitted personal data in process memory only. It is a development scaffold, not a production data store or authenticated order system.
- Before deploying, add authentication, authorization, input validation, rate limiting, secure persistence, and an appropriate privacy policy.
